How to use the Screen Test

Choose a solid color and look across the entire display for pixels or areas that appear different from the surrounding screen. Use the full-screen option for a larger test area.

Can a website detect dead pixels?

A normal website cannot reliably detect a dead or stuck pixel automatically. It can display controlled colors so you can inspect the screen yourself. A pixel that stays dark, bright or a different color across several backgrounds may need further testing.

Which colors should I test?

Black, white, red, green and blue backgrounds are useful for spotting different kinds of pixel or uniformity issues.
