How to test your keyboard

Click inside this page if necessary, then press the keys on your keyboard. A detected key will light up on the virtual keyboard. The tester also shows the key name and keyboard code reported by your browser.

What does this keyboard tester check?

DeviceTest can detect standard keyboard keys, function keys, modifier keys, arrow keys, numbers, letters, punctuation and other keys supported by your browser. It can also show which keys are currently being held down.

How to find a faulty keyboard key

Press each key once and check whether it lights up. If one key does not register while the surrounding keys work normally, reconnect your keyboard and test it again. You can also try another USB port or another computer. For wireless keyboards, check the battery and wireless connection.

What are KeyboardEvent key and code?

The key value describes the character or action generated by the keyboard, while code identifies the physical key position. This information can help determine exactly what your browser is detecting.

This online keyboard tester is a browser-based diagnostic tool. It does not install software or upload your keyboard input. Results can vary depending on your browser, operating system and keyboard hardware.
