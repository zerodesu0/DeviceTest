ABOUT DEVICETEST

Useful browser tools, without the hassle.

DeviceTest is an independent project focused on making everyday hardware testing simple, fast and accessible.

What is DeviceTest?

DeviceTest provides free browser-based tools that help you check whether your computer and connected devices are being detected correctly.

You can use DeviceTest to test devices such as mice, keyboards, microphones, webcams and gamepads without installing dedicated testing software.

Our approach

We aim to make each tool easy to understand and quick to use. Our tests show the information that modern web browsers can access about your device and its input.

Browser-based testing has limitations. A successful test cannot guarantee that every part of a device is working perfectly, and some hardware or driver problems cannot be diagnosed through a web browser. We try to make these limitations clear so that the results are useful rather than misleading.

Privacy

DeviceTest is designed around browser-based testing. Basic device tests run locally in your browser whenever the relevant browser APIs allow it. Microphone and webcam features require explicit browser permission.

For more information about how DeviceTest handles information, cookies and third-party services, see our Privacy Policy.

Our tools

DeviceTest currently provides free browser-based testing tools for common computer and phone hardware:

  • Mouse Test — buttons, movement, scrolling and supported extra buttons.
  • Mouse Double Click Test — double-click timing and accidental double-click behavior.
  • Keyboard Test — detected keys and keyboard input.
  • Gamepad Test — controller buttons, D-pad, sticks and triggers.
  • Microphone Test — live microphone input levels.
  • Webcam Test — camera access and video preview.
  • Touchscreen Test — taps, swipes and multi-touch input.
  • Screen Test — solid-color display inspection.
  • Speaker Test — browser audio test tones.
  • Device Info Test — browser-reported screen and device information.
